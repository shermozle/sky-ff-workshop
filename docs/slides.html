Sky NZ / How flags work12–14 min

Three operations, three timings

1

Fetch a decision

Network round trip plus service and SDK work.

2

Read a cached variant

Read an already fetched decision. No rule evaluation is implied.

3

Evaluate locally

Run rules against a user and cached configuration.

A quick cached read does not measure remote evaluation latency.
